```md
What is a data key?

A data key is a unique symmetric encryption key that is used to encrypt and decrypt data. In the context of AWS KMS (Key Management Service), a data key is generated by KMS and can be used for client-side or server-side encryption of data.

When you request a data key from KMS, it returns two versions of the key:
1. Plaintext Data Key: This is the actual encryption key that you can use to encrypt your data. It is in its raw, unencrypted form.
2. Encrypted Data Key: This is the same data key, but it has been encrypted using a specified KMS customer master key (CMK). This encrypted version can be safely stored or transmitted alongside the encrypted data.

So depending on the number of requests KMS charges code so comes the S3 bucket key lets you generate a short-lived bucket-level key from AWS Key that is temporarily stored in s3
This reduces the number of requests to KMS and lowers the cost of encryption operations.
When you enable S3 Bucket Key for a bucket that uses SSE-KMS, S3 automatically creates and manages a bucket-level key that is used to encrypt objects in that bucket. This bucket key is derived from the KMS customer master key (CMK) associated with the bucket.
When an object is uploaded to the bucket, S3 uses the bucket key to encrypt the object data. The bucket key is itself encrypted using the KMS CMK, ensuring that it remains secure.
When an object is accessed, S3 retrieves the bucket key, decrypts it using the KMS CMK, and then uses the decrypted bucket key to decrypt the object data.
When you enable S3 Bucket Key, S3 manages the lifecycle of the bucket key, including its rotation and deletion. The bucket key is short-lived and is automatically rotated by S3 on a regular basis to enhance security.
```

```sh

--body secret.txt \
--server-side-encryption aws:kms \
--ssekms-key-id alias/aws/s3 \
--bucket-key-enabled
```
